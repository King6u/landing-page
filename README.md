🚀 Custom Chrome Dashboard

A modern, cinematic, glassmorphism-inspired Chrome landing page built with HTML, CSS, and JavaScript. Designed to replace the traditional browser start page with a beautiful, interactive productivity dashboard.

✨ Features
🌅 Dynamic time-based greeting (Morning / Afternoon / Evening)
⏰ Live digital clock with animated updates
📅 Real-time date display
🌤️ Live weather information
💬 Rotating motivational quotes
🎥 Cinematic looping 4K background video
🌌 Animated aurora lighting effects
✨ Ambient floating particles
💡 Interactive mouse-following glow
🪟 Modern glassmorphism interface
📱 Fully responsive layout
⚡ Lightweight and built with vanilla JavaScript
🖼️ Preview

The dashboard combines modern UI principles inspired by:

Arc Browser
macOS Sonoma
Nothing OS
Windows 11 Fluent Design

Creating an elegant and distraction-free landing experience.

🛠️ Built With
HTML5
CSS3
Vanilla JavaScript (ES6)
OpenWeather API
Google Fonts (Inter)

🚀 Getting Started

Clone the repository:

git clone https://github.com/yourusername/custom-chrome-dashboard.git

Open the project:

cd custom-chrome-dashboard

Run using VS Code Live Server or any local web server.

⚙️ Configuration
Weather API

Replace your API key inside:

assets/js/weather.js
const API_KEY = "YOUR_OPENWEATHER_API_KEY";
Background Video

Replace:

assets/video/bg.mp4

with any MP4 cinematic background.

Recommended themes:

Rainy City
Misty Forest
Aurora
Mountains
Ocean
Night Sky
